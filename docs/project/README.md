# Expediente público de Bajo Pitocuna

Propuesta preliminar, sujeta a modificaciones y validación.

El usuario autorizó expresamente cargar los datos y planos en la web pública el 18/10/2026. Se conservan originales únicos y las fuentes de metrados, cronograma y APU. Los archivos temporales y duplicados no se incorporan.

Las vistas SVG comprimidas se derivaron de los DWG con LibreDWG a través de @mlightcad/libredwg-web 0.8.1, usado como herramienta local de conversión. Su biblioteca no forma parte de la aplicación distribuida. El lector informó advertencia 68. El encuadre inicial prioriza la geometría visible; las vistas no certifican reproducción íntegra, escala, cotas ni cantidades. El DWG original se puede descargar por separado.

Las asociaciones son documentales por tipología, componente y especialidad. Los nombres y jerarquías del expediente sostienen la clasificación. Por ejemplo, instalaciones eléctricas de primaria están dentro de un prefijo sanitario en el Excel: se usa el encabezado de especialidad, no solo el prefijo numérico. No se inventan ubicaciones de viviendas o frentes.

El proyecto contiene 718 tareas, 705 metrados no ambiguos y 514 rendimientos de referencia APU. Los datos de producción y compromisos permanecen vacíos. El WBS no está homologado con el código presupuestal. Las tres observaciones iniciales se conservan en la entrega de revisión: un TOTAL ausente y dos códigos repetidos en tratamiento, cuyas apariciones no se incluyen.
