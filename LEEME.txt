PITOCUNA — PROTOTIPO DE PRODUCCIÓN LPS + LBMS
PROPUESTA PRELIMINAR, SUJETA A MODIFICACIONES Y VALIDACIÓN.

Entrada: index.html servido por GitHub Pages o un servidor HTTP.
Para desarrollo local: npm ci --ignore-scripts; npm run dev.
No abrir mediante file://: la aplicación utiliza módulos JavaScript.

Recorrido: Datos de obra → Lookahead → Restricciones → Plan semanal → Avance → Indicadores.
En Datos de obra se importan cronograma XML/Excel/CSV y metrados Excel/CSV.
En ejemplos/ hay un Excel con dos hojas, CSV y XML ficticios para comprobar la carga.

El proyecto se guarda en este navegador; exporta respaldos JSON.
Puede reabrirse sin conexión tras una primera carga completa.
No tiene cuentas compartidas, servidor de registros ni sincronización automática.
Lee README.md y propuesta-funcional.md para conocer reglas y límites.
