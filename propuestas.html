Propuesta de uso sin internet

Registrar rápido. Conservar el contexto.

El mismo modelo de datos, con menos elementos visibles para facilitar el trabajo en campo.

  • Elegir ubicación y actividad.
  • Consultar restricciones y próxima acción.
  • Registrar observaciones y adjuntar evidencia.
  • Distinguir «guardado en dispositivo» y «sincronizado».
  • Revisar conflictos antes de consolidar cambios.
Alcance de esta propuesta: el selector y la consulta de fichas funcionan en la maqueta. La captura, los adjuntos, el cálculo local y la sincronización deben implementarse y probarse en la aplicación.

Decisiones visibles

Rojo para liberación estimada tardía; ámbar para margen cero; azul para información incompleta. Cada señal incluye texto y explicación.

Trazabilidad primero

Actividad + ubicación + responsable + fechas + evidencia + historial. Las estimaciones se distinguen de la liberación real.

Una base, cuatro vistas

Panel para planificar, tablero para coordinar, campo para capturar y LBMS para observar el avance. La selección final se puede validar con usuarios.

Basado en BORRADOR TESIS (2).pdf, §§ 1.6, 3.2, 3.3 y 4.3. Propuesta de diseño; no es una aplicación de gestión implementada. Sin dependencias externas, telemetría ni envío de información.
