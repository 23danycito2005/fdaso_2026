# Pitocuna · Maqueta LPS + LBMS

Propuesta de interfaz para una aplicación de gestión de restricciones y avance por ubicación en un proyecto de saneamiento rural.

## Descargar y abrir

1. En GitHub, pulsa **Code → Download ZIP** en esta rama.
2. Extrae el archivo completo.
3. Abre **index.html** en tu navegador.

No requiere instalación ni conexión a internet. Conserva los archivos HTML en la misma carpeta.

## Contenido

- `index.html`: portada que explica el proceso y presenta el avance de obra.
- `propuestas.html`: demo con panel operativo, tablero por estados, vista de campo y avance LBMS.
- `avance-obra.html`: esquema de obra y gráfico tiempo–ubicación; permite seleccionar tramos y mover el corte de ejemplo.
- `propuesta-funcional.md`: propuesta funcional y orden de implementación.
- Imágenes PNG: capturas del diseño en computadora y celular.
- `pitocuna-completo.zip`: paquete con la maqueta, documentación y capturas.

## Alcance

Es una maqueta visual con datos ficticios, no una aplicación operativa. La vista de UBS está reservada para su diseño con datos autorizados. No implementa almacenamiento de registros de obra, usuarios, adjuntos reales ni sincronización. Los gráficos no acreditan resultados de obra ni conformidad técnica.

Diseño preparado a partir del borrador de tesis y de una referencia visual aportados por el usuario. Los archivos originales de esos documentos no están incluidos.
